TP07 - Vue.js + PHP (Fetch / Axios)

1. Copier le dossier "tp07" dans htdocs (XAMPP) ou www (WAMP).
2. Importer sql/tp07.sql dans phpMyAdmin.
3. Adapter user / mot de passe dans backend/config.php si besoin.
4. Ouvrir :
   http://localhost/tp07/frontend/partie1.html
   http://localhost/tp07/frontend/partie2.html
   http://localhost/tp07/frontend/partie3.html
(La partie 3 a besoin d'Internet et de l'extension PHP cURL activée.)
